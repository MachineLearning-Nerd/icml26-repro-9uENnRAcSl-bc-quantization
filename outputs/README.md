# Output boundary

`verdict.json` and `verify_run.log` are the original prototype outputs. They
record an early four-of-six result and are retained unchanged for provenance.

The authoritative current finite evidence is under
[`repro/release_snapshot/evidence`](../repro/release_snapshot/evidence), with
source audits, raw results, provenance, manifests, independent checkers, and
negative controls. Use [AUDIT_REPORT.md](../AUDIT_REPORT.md) for the current
interpretation and [GATE_READY.md](../GATE_READY.md) for the publication gate.
